PUBLIC CONFIGURATION

Pengaturan merchant

Atur Shellback Reward, aset QR, dan kontak WhatsApp. Simpan lokal untuk browser ini atau ekspor konfigurasi untuk diterbitkan di GitHub.

Global update = GitHub commit. Menekan Simpan hanya mengubah browser ini. Untuk semua pengunjung, ekspor `kantin-config.json` lalu unggah dan commit file tersebut ke repository.

Voucher Shellback Reward 🐚

Kode hanya diberikan admin melalui WhatsApp setelah pembeli mengonfirmasi membawa wadah sendiri. Jangan menganggap kode dalam front-end sebagai rahasia yang aman.

Format internasional tanpa tanda +, spasi, atau tanda hubung.

Simpan gambar QRIS resmi pada folder repository sesuai path ini. Tidak membuat QRIS otomatis.

Gunakan QR akun resmi merchant, bukan QR buatan yang belum diverifikasi.

Publish checklist

Untuk menyebarkan menu, stok, dan voucher ke seluruh pengunjung website.

1
Atur katalog dan voucher

Simpan perubahan di browser admin.

2
Ekspor `kantin-config.json`

File berisi produk publik, harga, stok awal, dan pengaturan voucher/QR.

3
Unggah ke repository

Ganti file di root repo dan commit changes.

4
Tunggu publikasi selesai

Pengunjung akan membaca config yang baru ketika GitHub Pages telah memperbarui situs.

Karena kode voucher berada di website statis, orang yang mengetahui kode dapat menirunya. Pemberian voucher manual melalui WhatsApp membantu alur, tetapi tidak dapat ditegakkan sebagai kontrol rahasia tanpa backend.

Impor backup penuh
