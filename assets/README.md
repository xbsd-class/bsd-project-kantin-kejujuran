# Aset yang perlu ditambahkan oleh pengelola

Sebelum transaksi nyata, letakkan gambar QRIS resmi merchant di folder ini dengan nama `qris.png`.

Opsional: letakkan QR akun WhatsApp resmi di folder ini dengan nama `whatsapp-qr.png`.

Nama/path bisa diubah melalui konfigurasi `kantin-config.json`, tetapi setiap gambar harus ikut diunggah dan di-commit ke repository GitHub agar terlihat oleh pengunjung lain. Jangan gunakan QRIS palsu atau QR yang belum diperiksa nama penerimanya.
